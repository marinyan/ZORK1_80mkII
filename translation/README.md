# 翻訳データ

翻訳は、校正しやすい通常の日本語で作成する。半角カナ化、文字数削減、実機用文字コードへの変換は、この仮訳が固まった後の別工程とする。

## ディレクトリ

- `catalog/rooms.tsv`: 部屋名と固定の部屋説明
- `catalog/objects.tsv`: 物体名と固定の物体説明
- `catalog/messages.tsv`: 行動やイベントで表示されるメッセージ
- `catalog/commands.tsv`: `SYNTAX`で定義された入力構文
- `catalog/strings.tsv`: 判定保留分を含む全ZIL文字列と構文上の位置
- `ja/rooms.tsv`: 部屋名と固定説明の日本語仮訳
- `ja/objects.tsv`: 物体名と固定説明の日本語仮訳
- `ja/messages.tsv`: 動的メッセージの日本語仮訳
- `ja/verbs.tsv`: 英語動詞に対応する日本語入力語の案
- `ja/directions.tsv`: 方角の日本語入力語の案

カタログは次のコマンドで再生成できる。

```powershell
./tools/extract-zil-catalog.ps1
```

翻訳IDの過不足は次のコマンドで検査する。

```powershell
./tools/test-translation-catalog.ps1
```

## 状態

- `machine-draft`: 機械翻訳による全件初訳。原文との照合と日本語校正が必要
- `draft`: 普通の日本語による初回仮訳
- `format`: 空白、字下げ、デバッグ記号など翻訳しない制御用文字列
- `reviewed`: 原文との照合と日本語校正を完了
- `final`: 実機用表現へ変換する基準訳として確定

動詞の`disposition`は、`keep`が初期版でも採用、`consider`が仕様検討、`defer`が保存媒体などの設計待ち、`omit`が初期版から省略する候補を表す。
