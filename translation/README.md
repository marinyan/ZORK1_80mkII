# 翻訳データ

翻訳は、校正しやすい通常の日本語で作成し、ゲーム本文の文体は「だ・である」調の常体に統一する。半角カナ化、文字数削減、実機用文字コードへの変換は、この仮訳が固まった後の別工程とする。

## ディレクトリ

- `catalog/rooms.tsv`: 部屋名、固定の部屋説明、出口専用メッセージ
- `catalog/objects.tsv`: 物体名と固定の物体説明
- `catalog/messages.tsv`: 行動やイベントで表示されるメッセージ
- `catalog/commands.tsv`: `SYNTAX`で定義された入力構文
- `catalog/strings.tsv`: 判定保留分を含む全ZIL文字列と構文上の位置
- `ja/rooms.tsv`: 部屋名、固定説明、出口専用メッセージの原文・日本語仮訳・出典
- `ja/objects.tsv`: 物体名と固定説明の原文・日本語仮訳・出典
- `ja/messages.tsv`: 動的メッセージの原文・日本語仮訳・出典
- `ja/verbs.tsv`: 英語動詞に対応する日本語入力語の案
- `ja/directions.tsv`: 方角の日本語入力語の案
- `ja/input.tsv`: 優先する日本語入力語と原作パーサー語の対応
- `ja/ui.tsv`: Windows検証版固有の表示文
- `en/`: 原文をそのまま表示する英語言語パック。同じ7種類のTSVを持つ

カタログは次のコマンドで再生成できる。

```powershell
./tools/extract-zil-catalog.ps1
```

英語言語パックは原典カタログから再生成できる。

```powershell
./tools/build-english-language-pack.ps1
```

再生成したカタログの原文と出典を翻訳TSVへ反映する場合は、次を実行する。`japanese`、`status`、`notes`列にある既存の編集はIDで引き継がれる。

```powershell
./tools/update-translation-context.ps1
```

翻訳IDの過不足は次のコマンドで検査する。

```powershell
./tools/test-translation-catalog.ps1
```

翻訳TSVは、`english`の直後に`japanese`を置いている。特に動的メッセージは複数の断片を実行時に連結するため、`routine`、`source_file`、`line`も参照して前後関係を確認する。

## 状態

- `machine-draft`: 機械翻訳による全件初訳。原文との照合と日本語校正が必要
- `draft`: 普通の日本語による初回仮訳
- `format`: 空白、字下げ、デバッグ記号など翻訳しない制御用文字列
- `reviewed`: 原文との照合と日本語校正を完了
- `final`: 実機用表現へ変換する基準訳として確定

動詞の`disposition`は、`keep`が初期版でも採用、`consider`が仕様検討、`defer`が保存媒体などの設計待ち、`omit`が初期版から省略する候補を表す。

## 入力名と表示名

物体の表示名は「白い家」「幽霊たち」のような自然な日本語とし、プレイヤーが入力できる呼び名は`ja/input.tsv`で追加する。「家／白い家」のように形容語は省略可、「幽霊／幽霊たち」のように単数・複数表現はどちらも受け付ける。修飾語を省いて複数候補に該当したときは、原作パーサーの候補確認をそのまま利用する。色違いのボタンなど区別が必要な表現は、形容語を含む入力も原作辞書の複数語に変換する。

部屋、物体、動的メッセージは全件を原文とルーチン単位で照合し、普通の日本語で再翻訳した。本文と応答は「だ・である」調の常体に統一し、機械初訳は残していない。状態を`draft`としているのは、全経路を実際にプレイした最終校正と、実機用の短縮・半角カナ化がまだ残っているためである。

Windows検証版の自動進行では、開始地点から家へ入り、ランタンを操作して終了するまでを日本語入力で確認している。数値や物体名を途中へ差し込む文は日本語の語順に合わせて断片を組み直しているが、同一の短い英語断片が別の文脈で使われる箇所は、引き続きプレイしながら確認する必要がある。
